# phpStudy 导入插件迁移计划

## 目标和文件归属

- 将站点导入迁移到 plugins/phpstudy-import，插件 ID 与模块 ID 均为 phpstudy-import，版本为 0.1.0。
- render 目录拥有三步界面、核对草稿与操作控制器，fork 目录拥有扫描、验证、备份及逐项导入，shared/types.ts 仅保存插件契约。
- 移除 src 中本功能的内置注册、页面及专属后台目录。通用 Host 写入锁及原子保存继续由宿主框架提供，插件打包复用这些框架代码。
- 使用宿主 IPC、AppStore、BrewStore 和版本管理组件。站点刷新调用宿主 AppStore.initHost，hosts 同步调用宿主 host.writeHosts，避免打包另一份 HostStore。
- 插件源码与发布脚本集中在插件目录，发布独立 flyenv-plugin 包和本地 registry.json。

## 操作契约与约束

- 不新增 Pinia 或 config.setup 字段，无约束例外。来源偏好沿用 StorageGetAsync/StorageSetAsync。
- 页面拥有选择和草稿。单例控制器跨页拥有扫描、导入快照、进度、通知、重复调用保护和 IPC 清理。
- 插件 scan/importSites 使用 app-fork:phpstudy-import，code 200 仅更新进度，0/1 释放监听并保留终态。
- 扫描只读来源，导入前备份为共享必要依赖。每个站点独立失败，继续其他有效项，已完成结果保留。hosts 同步和视图刷新为附加步骤，失败不重放导入。
- 插件不启动服务，PHP 安装复用宿主既有版本组件生命周期。
