# phpStudy 插件选择与筛选调整

- 版本升级为 0.1.1，交付独立插件包和本地安装源。
- 表格四列为展开、站点、来源 PHP、迁移 PHP。站点表头及每行域名前放复选框，支持全选、取消及半选。
- 表头选择作用于当前筛选中的可选择站点，隐藏项保留选择，页面显示筛选外已选数。
- 域名模糊匹配主域名与别名，来源 PHP 和 Web 服务精确筛选，三个条件同时生效。合并来源包含 Nginx 和 Apache 时可由任一服务筛选命中。
- 移除核对列和逐项确认状态，点击确认导入时提交确认快照。PHP 版本、重复域名及配置问题继续由既有校验处理。
- 筛选与选择属于页面草稿，保持现有模块单例扫描/导入生命周期。Web 来源元数据属于插件扫描结果。无新 Pinia 或 config.setup 字段，无约束例外。
- 失败边界沿用既有逐站点处理。过滤只影响显示及表头选择范围，不能自动扩大导入范围或清空隐藏项选择。
- 验证筛选组合、合并来源、空结果、禁用项、半选和隐藏选择，运行现有导入、插件安装与边界检查，构建新版插件。
