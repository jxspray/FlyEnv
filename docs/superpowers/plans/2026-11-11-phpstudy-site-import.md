# phpStudy 站点导入模块实施计划

> 按用户已确认流程在当前会话逐项实施。

## 目标与边界

- 新建 Windows 站点导入模块，扫描 E:\phpstudy_pro，核对站点和 PHP，确认后按真实完成数展示进度。
- 模块代码放在 renderer SiteImport 与 fork SiteImport 目录，复用 Host 创建及 PHP 版本目录。无新 Pinia、共享配置字段或数据库变更，无约束例外。
- 页面拥有输入、选择和编辑草稿。单例控制器拥有扫描快照、运行状态、结果、IPC 清理及重复调用保护。来源路径使用 StorageGetAsync/StorageSetAsync 保存。
- fork 扫描只读来源配置。导入前重新校验来源指纹、PHP 可执行文件、目录和域名冲突，备份目标站点列表及 vhost。每项复用 Host.handleHost，站点写入串行并加跨 worker 锁。
- PHP 安装入口复用现有 PHP 版本管理页，返回后刷新列表。按完整版本优先匹配，选中站点须明确确认版本与配置。

## 操作契约

| 操作 | 所有者及生命周期 | 中间事件与终态 | 重入与服务交互 |
| --- | --- | --- | --- |
| 扫描 | SiteImportController，跨页面保留 | code 200 保留监听，0 成功，1 失败释放监听 | 运行中拒绝重复扫描；不启动服务 |
| 导入 | SiteImportController 与 fork SiteImport，跨页面保留 | 每项开始/结果，最终结果包含成功失败跳过和备份路径；0/1 清理监听 | 请求深拷贝；运行中拒绝重入；写入后 hosts 同步是附加步骤，服务按既有生命周期手动启用 |

## 失败归属

- 目标备份及可靠站点列表为共享必要依赖，失败则停止导入。
- 站点来源变更、版本缺失、重复站点、目录缺失只影响单项，继续有效兄弟项。
- 单项配置生成失败清理该新 ID 文件，保留先前完成站点。站点列表保存结果须回读核对，未知状态不自动重试。
- hosts 同步、视图刷新和偏好持久化失败只记录各自警告，不覆盖已完成导入结果。

## 审查重点

- 无法可靠识别的配置必须明确报告，不能静默丢失代理或伪静态。
- PHP 与来源不一致必须由用户确认，执行前再次核对实际已安装版本。
- 重复导入与并发 Host 添加不能覆盖既有站点。
- 页面离开时任务仍保留，监听只在终态移除。
- 写入后附加步骤失败不能触发整批重放。
