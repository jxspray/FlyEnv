# 移除功能授权限制实施计划

## 目标与范围

根据用户要求移除本地功能的激活码、数量和试用期限门槛。授权账号页面继续显示真实状态。

## 实施步骤

- [x] 删除 Host、Image、Ollama Fork 中的授权拒绝分支。
- [x] 移除渲染层站点、项目、自定义模块、任务、启动组、代码库、隧道、截图、压缩及 AI 的授权门槛和启动过期提醒。
- [x] 删除插件安装、更新与旧记录迁移的授权条件，保留安装记录及内容校验。
- [x] 执行 ESLint、现有生命周期与启动组测试，检查未激活和已有过期试用数据的入口。
- [x] 按日期记录日志、需求及用户提示词。

## 所有权与操作契约

本次删除操作前置限制，沿用现有操作所有者，无新增模块、持久化、Pinia 或状态。没有约束例外。

站点写入由 Host Fork 所有，压缩和聊天由原 Fork 模块所有，插件安装由 PluginManager 所有。操作生命周期、进度、终态、重复调用保护及进程交互沿用原入口。截图配置仍经原 IPC 更新。测试覆盖既有生命周期边界、启动组操作和插件安装。

移除的授权步骤不再是必要依赖。实际写入、下载、校验与进程操作仍是各自必要依赖，错误继续向所属操作传播。旧试用时间参数保留 IPC 兼容性，但不再影响执行。

## 审查重点

未激活、无效激活码、离线、已有过期试用数据均可使用本地功能。账号状态保持真实。插件来源、安装记录、哈希和 API 版本校验仍按原逻辑执行。

## 验证结果

启动组、渲染操作边界及语言项目端口契约通过 Node 原生 TypeScript 转换执行。授权门槛源码检查和修改脚本语法检查通过。当前目录缺少依赖，Yarn 入口因 tsx 缺失失败，完整 ESLint、类型检查、构建及桌面操作仍待验证。
