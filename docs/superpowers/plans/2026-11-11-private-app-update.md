# 自定义应用更新源实施计划

## 目标

- 接管关于我们检查更新与启动自动检查，使用用户配置的更新目录。
- 暂无远程地址，默认空更新源，通过本地 HTTP 服务验证元数据和下载安装包。
- 发布 Windows NSIS 完整安装包、latest.yml、blockmap。补丁升级版本为 4.20.3，首次安装后支持后续私有源更新。

## 归属及操作契约

- About/UpdateController 单例拥有 renderer 检查、下载、安装 IPC、状态与监听清理，页面仅持有更新源编辑草稿。
- UpdateManager 主进程拥有 electron-updater 及安装进程生命周期，按需加载。
- code 200 为中间状态，0/1 为终态。运行期间拒绝重入与换源，离开页面后继续任务并保留结果。
- 检查读取目录下 latest.yml，下载由 electron-updater 校验 SHA-512。安装前复用 Application.stop，停止完成后调用 quitAndInstall。
- 更新源用 StorageGetAsync/StorageSetAsync 保存，不增加 Pinia 或 config.setup 字段，无约束例外。

## 失败边界

- 空源禁止网络请求，自动检查静默跳过，手动检查提示配置。
- 元数据、下载、哈希校验失败为必要步骤失败，不允许安装。
- 安装前停止失败不得触发安装。偏好存储失败保留原更新源。
- 下载结果保留到用户确认安装；通知失败不覆盖已下载状态。
