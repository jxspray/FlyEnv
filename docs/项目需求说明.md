### phpStudy 站点导入流程

- 来源为 E:\phpstudy_pro，流程为扫描、逐站点核对、进度导入。
- 扫描后展示域名、根目录、端口、SSL、伪静态和来源 PHP 版本，合并同一站点的 Nginx/Apache 配置并标出差异。
- 每个选中站点须确认目标 FlyEnv PHP 版本；优先匹配已安装的相同版本，缺失时提示安装该版本或选择其他已安装版本，版本准备完成后重新检查。
- 支持同来源 PHP 版本批量匹配；导入前展示站点总数、版本映射及冲突，存在未确认版本或阻断项的选中站点时不可开始。
- 导入展示整体进度条、完成数/总数、当前站点和逐项成功/失败/跳过结果；独立站点失败后继续，结果可回看。
- 默认引用原项目目录、追加站点并识别重复，导入前备份 FlyEnv 站点配置。

## 2026-11-11 站点导入模块与应用更新

- 站点导入作为独立 Windows 模块，按扫描、核对 PHP、进度导入三步执行；支持逐项编辑、批量版本匹配、追加导入、备份与重复识别。
- PHP 站点复用现有主次版本运行服务，同一主次版本的导入项须选择相同完整版本。
- 关于我们接管更新检查，更新目录独立配置；暂无远程地址时默认空源，支持本地 HTTP 测试。
- Windows 版本升级为 4.20.3，发布安装包、latest.yml 和 blockmap，下载校验通过后由用户确认停止服务并安装。

### 2026-11-11 独立插件交付

- 将站点导入迁移为可独立安装和升级的 phpstudy-import 插件，保留三步流程及 PHP 核对。
- 通过现有插件管理安装，交付插件包和本地安装源；入口名为 phpStudy 导入。现有 4.20.3 可隐藏早期内置入口。

### 2026-11-11 插件 0.1.1 选择与筛选

- 表格为展开、站点、来源 PHP、迁移 PHP 四列，站点表头和行内使用复选框，支持半选，移除核对列和逐行确认。
- 按域名及别名、来源 PHP、Apache/Nginx 组合筛选。全选/取消作用于当前筛选范围，隐藏项保留选择并展示数量。
- 点击确认导入提交当前选择与 PHP 映射，继续校验版本、配置和重复站点。
