下方重点接口已经沿实际调用点核对。附录记录代码中的外部 HTTP/HTTPS 地址候选，其中包含下载地址、浏览器链接、文档说明及模板默认值，各候选的出现并不表示启动时都会访问。查询参数内容统一隐藏。依赖包内部行为、外部程序自身的网络请求以及服务端重定向产生的新域名需要运行时流量验证。

## FlyEnv 自有许可证链路清理

已经删除以下接口及其上游账号、页面、IPC、状态广播、本地 RSA 验证和许可证读写链路。

| 原接口 | 原用途 | 原请求字段 |
| --- | --- | --- |
| POST api.one-env.com/api/app/active_code_info | 查询机器激活码 | uuid |
| POST api.one-env.com/api/app/active_code_request | 申请激活码 | uuid、user_uuid、message |
| POST api.one-env.com/api/app/user_github_auth | 读取许可证页面的 GitHub 用户信息 | user_uuid、uuid |
| POST api.one-env.com/api/app/user_github_auth_by_code | 许可证账号登录交换 | uuid、code |
| POST api.one-env.com/api/app/user_github_license | 获取许可证列表 | user_uuid、uuid |
| POST api.one-env.com/api/app/user_github_license_add | 绑定许可证 | user_uuid、uuid、license |
| POST api.one-env.com/api/app/user_github_license_del | 解绑许可证 | user_uuid、uuid、license |
| github.com/login/oauth/authorize | 许可证账号的浏览器授权 | client_id、redirect_uri、scope 等 |

上述功能的唯一界面入口为原许可证页。设置页的标签状态继续由 SetupStore 持有。旧用户配置中的许可证字段不再读取或广播，截图初始化直接调用其已有控制器。

## 动态地址及本地服务

- 插件包、版本压缩包和模型文件的目标地址可由在线目录返回，不能仅靠源码 URL 字面量列举完整域名。
- 网站下载工具 SiteSucker 根据用户输入 URL 及页面资源发起请求，目标页面本身也可能加载其他资源。
- 数据库连接、DNS 转发、SSH、FTP、代理及容器镜像拉取可能使用其他协议或外部二进制，最终目标取决于用户配置。
- MCP 默认监听 127.0.0.1:7682，Ollama 默认 127.0.0.1:11434，其他管理面板及服务健康检查主要使用本地地址。它们的外部调用属性由实际配置决定。
- About 中 flyenv.com/license.html 是用户点击打开的赞助网页。依赖和第三方服务的开源许可声明、RustFS 的 RUSTFS_LICENSE 启动参数均有各自用途。
